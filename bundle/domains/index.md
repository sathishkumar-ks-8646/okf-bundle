# API domains

# Subdirectories

* [Organization Management](organization-management/) - APIs that return information about the organisations, resource usage, subscription plan, and workspace or view identity lookups available to the authenticated user.
* [Users & Groups](users-and-groups/) - API for managing users and groups in Zoho Analytics — covering org-level users, workspace-level users, and workspace groups.
* [Workspace Management](workspace-management/) - API for managing workspaces in Zoho Analytics — covering workspace operations, preferences, domain access, and folder management.
* [Data Modeling & Schema](data-modeling-and-schema/) - API for Data Modeling & Schema in Zoho Analytics — covering tables, schema, columns, lookups, query tables, formulas, and workspace variables.
* [Data Operations](data-operations/) - API for Data Operations in Zoho Analytics — covering row operations, import/export workflows, and datasource sync/connectivity.
* [Views Management](views-management/) - API for Views Management in Zoho Analytics — covering view operations, auto analysis, favorites, and trash management.
* [Reports & Dashboards](reports-and-dashboards/) - API for Reports and Dashboards in Zoho Analytics - covering the creation, update and metadata retrieval of analysis views, and the listing, creation, metadata retrieval and update of dashboards.
* [Share & Publish](share-and-publish/) - API for Share & Publish in Zoho Analytics — covering view sharing, publish configurations, embed URLs, and slideshow management.
* [Schedules & Alerts](schedules-and-alerts/) - API for Schedules & Alerts in Zoho Analytics — covering creation, management, and triggering of email schedules.
* [Data Science & Machine Learning (AutoML)](dsml/) - API for DSML (Data Science & Machine Learning) in Zoho Analytics — covering AutoML analysis creation, execution, deployments, and what-if analysis.
